# Security Policy

## Supported Versions

Security updates and patches are applied to the latest release of Alloy.

| Version | Supported          |
| ------- | ------------------ |
| 0.2.x   | :white_check_mark: |
| 0.1.x   | :white_check_mark: |
| < 0.1.0 | :x:                |

## Reporting a Vulnerability

We take the security of Alloy seriously. If you discover a potential vulnerability, please do not disclose it publicly via GitHub issues or discussions.

### Reporting Process

1. **Email Us**: Send details of the vulnerability to `rdxdevbhai76@gmail.com`.
2. **Details to Include**:
   - Description of the vulnerability and its potential impact.
   - Minimal reproduction script or test case (e.g. JavaScript or Python snippet).
   - Affected platforms or configurations (Windows, Linux, macOS, Cranelift JIT enabled/disabled).
   - Any suggested remediations or patches.

### Response Timeline

- **Initial Acknowledgment**: Within 48 hours of receipt.
- **Assessment & Reproduction**: Within 5 business days.
- **Patch & Advisory**: Coordinated release and CVE assignment (if applicable) within 30 days.

Thank you for responsibly disclosing security vulnerabilities to keep the Alloy ecosystem safe!
